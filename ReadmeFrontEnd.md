VoiceAssistantMobileApp

A mobile voice assistant app built with react Native and Expo. It uses OpenAI for voice transcription and chat responses.

Features

Voice chat powered by OpenAI API

Android/iOS support via Expo Go

Easy testing using QR code scanning

Requirements

Node.js and npm installed

Expo CLI (npm install -g expo-cli)

OpenAI API key set in app.json under extra.OPENAI_API_KEY

Mobile device with Expo Go installed

How to Run

Clone the repository:

git clone https://github.com/Jojo991/VoiceAssistantMobileApp.git
cd VoiceAssistantMobileApp


Install dependencies:

npm install


Start the Expo development server:

npx expo start


Open Expo Go on your mobile device and scan the QR code displayed in the terminal or browser.

The app will run on your device for testing.
